### [0:00 - 0:25] Opening Scene: The Stateless AI Problem
*(Visual: Screen showing standard chatbot outputting "Post 5 tips for social growth" vs SocialMind AI logo)*

**Speaker:**  
"Every creator has tried asking AI for content advice, and almost everyone gets the same generic answer: 'Post consistently and use good hashtags.' 

The problem isn't the LLM model — it's context loss. Traditional AI chat has no persistent memory of your previous post performance, audience feedback, or past content experiments."

### [0:25 - 1:15] Introducing SocialMind AI & Hindsight Architecture
*(Visual: Dashboard overview, moving to Architecture Diagram)*

**Speaker:**  
"Meet **SocialMind AI**, an AI social media strategist built around **Vectorize Hindsight**, a biomimetic agent memory system.

Instead of stuffing thousands of raw metrics into every prompt, SocialMind AI uses a dual-engine architecture:
- PostgreSQL manages structured post tables and exact engagement calculations.
- Vectorize Hindsight acts as the persistent agent memory bank — storing creator preferences, audience demographics, and performance facts across 6 memory categories."

### [1:15 - 2:00] Live Demonstration: Before vs After Hindsight Memory
*(Visual: Switching to Memory Demo Page)*

**Speaker:**  
"Let's look at the before and after.

Without memory, asking *'What should I post next?'* yields a generic advice template.

Now, we activate Hindsight memory, storing facts about creator Alex's short-form Python reels reaching 72,000 views and his college student audience requesting debugging tutorials.

Asking the exact same question produces a hyper-personalized recommendation: a 35-second beginner Python debugging reel with an exact hook, citing the 4 recalled historical facts from Hindsight."
